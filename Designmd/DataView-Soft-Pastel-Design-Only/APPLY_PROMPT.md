# 디자인 적용 지시문

아래 내용을 구현 담당자 또는 코딩 에이전트에 그대로 전달할 수 있습니다.

---

기존 DataView의 기능 구현은 완료되어 있습니다. 제공된 `DataView-Soft-Pastel-Design-Only` 패키지를 기준으로 **시각 디자인만** Soft Pastel 테마로 변경해 주세요.

반드시 지킬 범위:

- 기존 데이터 모델, 계산, 상태 관리, 저장, 네트워크, 권한, Widget Timeline 로직을 변경하지 마세요.
- 기존 화면 이동, 딥링크, 버튼 동작, 탭 동작과 접근성 레이블의 의미를 변경하지 마세요.
- 새로운 기능, 화면, 설정 항목 또는 사용자 흐름을 추가하지 마세요.
- 컴포넌트를 새로 작성하기 전에 기존 컴포넌트에 테마 토큰을 적용할 수 있는지 먼저 확인하세요.
- 변경은 색상, 타이포그래피, 간격, 카드 표면, 모서리, 그림자, 게이지·차트 외형과 제공된 이미지 자산 적용으로 제한하세요.
- 파스텔 색은 배경과 데이터 구분에 사용하고, 본문과 핵심 수치는 고대비 잉크 색을 사용하세요.
- 화면별 스타일은 `docs/02_APP_STYLING.md`, 위젯은 `docs/03_WIDGET_STYLING.md`를 따르세요.
- 구현 결과는 `assets/png/reference/Ref-Overview.png`와 비교하되, 기존 앱의 기능 구조가 기준 이미지와 다르면 기존 구조를 유지하세요.
- 수정 후 기능 테스트는 회귀 확인 목적으로만 실행하고, 실패를 고치기 위해 비주얼 범위를 넘어서는 로직 수정은 하지 마세요.

완료 시 변경한 디자인 파일과 컴포넌트만 요약하고, 기능 로직을 변경하지 않았음을 확인해 주세요.
