# 05. 디자인 적용 완료 기준

이 체크리스트는 기능 검증이 아니라 **시각 회귀와 디자인 품질** 확인용입니다.

## 범위

- [ ] 변경 파일이 테마, 스타일, 레이아웃과 이미지 자산에 한정된다.
- [ ] 데이터 모델, 계산, 상태 관리, 네트워크 및 위젯 Timeline 파일은 변경되지 않았다.
- [ ] 기존 화면 이동과 컨트롤 동작이 유지된다.

## 색상과 타이포그래피

- [ ] 앱과 위젯이 같은 Soft Pastel 토큰을 사용한다.
- [ ] 파스텔 색은 표면과 데이터 계열에 사용되고 작은 본문에는 사용되지 않는다.
- [ ] 핵심 숫자는 Text Primary와 Bold Rounded 스타일로 일관된다.
- [ ] 숫자 갱신 시 폭이 흔들리지 않는다.
- [ ] Light/Dark에서 텍스트가 배경과 충분히 구분된다.

## 레이아웃

- [ ] 화면 좌우 여백과 카드 간격이 일관된다.
- [ ] 카드 radius와 그림자가 화면마다 달라지지 않는다.
- [ ] 카드가 불필요하게 중첩되지 않는다.
- [ ] 320 pt 너비와 기준 393 pt 너비에서 겹침이나 잘림이 없다.
- [ ] 큰 Dynamic Type에서도 콘텐츠가 고정 높이에 잘리지 않는다.

## 앱 화면

- [ ] 홈 Hero에서 게이지 → 남은 데이터 → 사용량 순서가 명확하다.
- [ ] 통계에서 선택 기간과 선택 막대가 명확하다.
- [ ] iPhone은 Sky, 핫스팟은 Lavender로 일관되게 표시된다.
- [ ] 설정의 Soft Pastel 선택 상태가 체크와 텍스트로 보인다.
- [ ] 활성 탭과 비활성 탭이 색 이외의 배경 처리로도 구분된다.

## 위젯

- [ ] Small에서 퍼센트와 남은 데이터가 한눈에 읽힌다.
- [ ] Medium에서 남은 데이터가 가장 높은 시각 위계를 가진다.
- [ ] 잠금화면 위젯이 monochrome/tinted 렌더링에서 유지된다.
- [ ] WidgetKit 기본 여백과 모서리가 훼손되지 않는다.

## 자산

- [ ] AppIcon이 1024px 원본으로 등록되며 앱에서 추가 모서리 마스크를 적용하지 않는다.
- [ ] Mesh가 늘어나거나 찌그러지지 않는다.
- [ ] 장식 이미지가 핵심 텍스트를 가리지 않는다.
- [ ] `assets/png/reference/Ref-Overview.png`와 전체 인상이 일치한다.
