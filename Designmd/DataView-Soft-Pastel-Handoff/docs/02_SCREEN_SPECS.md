# 02. 화면 명세

기준 캔버스는 iPhone 15 Pro의 393 × 852 pt입니다. 기준 PNG는 3x(1179 × 2556 px)이며, 상태바와 홈 인디케이터를 포함한 시각 검수용 시안입니다.

## 공통 셸

- Safe area를 준수하고 좌우 기본 여백 20 pt.
- 상단 제목 영역 44 pt, 콘텐츠는 세로 스크롤.
- 하단 탭 바는 시스템 탭 구조를 사용하며 높이를 직접 고정하지 않음.
- 선택 탭: `accent.mintStrong`, 비선택 탭: `text.tertiary`.
- 네트워크 갱신 중에도 기존 값을 유지하고 제목 옆에 작은 진행 표시만 노출.
- Pull to refresh를 제공하되 마지막 갱신 시각은 콘텐츠 최하단 또는 오류 상태에서만 노출.

## A. 홈 / 데이터

주요 사용자 작업: 이번 달 남은 데이터와 현재 사용 추세를 3초 안에 확인.

### 레이아웃 순서

1. 화면 제목 `데이터` + 우측 갱신 버튼
2. 월간 요약 Hero 카드
3. `오늘 사용량` 카드
4. `최근 7일` 차트
5. 갱신 메타 정보

### 월간 요약 Hero 카드

- 높이: 최소 220 pt, Dynamic Type에서 확장.
- 배경: `background.elevated`, radius 24, `shadow.card`.
- 좌측: 126 pt 원형 게이지, stroke 13 pt.
- 우측: `남은 데이터`, `87.6 GB`, `160 GB 중 72.4 GB 사용`.
- 하단: 갱신일 캡슐 `9월 25일 갱신`.
- 게이지의 시작점은 12시, 진행 방향은 시계 방향.
- 소수 표기: 100 GB 이상 1자리, 10 GB 미만 최대 2자리.

### 오늘 사용량 카드

- 높이: 138 pt.
- 상단: `오늘 사용량` + 합계 `1.86 GB`.
- 하단 2열: iPhone(스카이), 핫스팟(라벤더).
- 각 열은 작은 색상 점, 레이블, 값으로 구성. 카드 중첩 금지.

### 최근 7일 차트

- 높이: 190 pt.
- 막대 7개, 오늘 막대는 `accent.mintStrong`, 이전 날은 `accent.sky` 70%.
- y축 라벨은 생략하고, 최대값/평균을 요약 문장으로 제공.
- 선택 가능한 차트라면 선택 지점의 날짜와 값을 상단에 표시.

### 상태

- Loading: 숫자 영역과 차트에만 skeleton, 제목/탭은 유지.
- Empty: `이번 달 사용 기록이 아직 없어요` + 선택적 EmptyState 이미지.
- Error: 카드 상단에 인라인 오류 배너. 기존 캐시 값과 `마지막 업데이트`를 유지.
- Over quota: 게이지를 danger로 변경하고 `한도를 초과했어요` 문구 표시.

참조: `assets/png/reference/Ref-Screen-Home@3x.png`

## B. 통계

주요 사용자 작업: 기간별 사용 추세와 iPhone/핫스팟 비중 비교.

### 레이아웃 순서

1. 제목 `통계`
2. 기간 세그먼트 `주 / 월`
3. 선택 기간 총 사용량
4. 일별 막대 차트
5. 사용처 비중
6. 최고 사용일 인사이트

### 기간 세그먼트

- 전체 높이 36 pt, `background.subtle`, radius pill.
- 선택 배경 `background.elevated`, 얕은 shadow.
- 탭 변경 시 차트가 수평 이동하지 않고 crossfade.

### 차트

- 플롯 높이 210 pt.
- 막대 최소 시각 폭 8 pt, hit target은 36 pt 이상.
- 기준선 3개, `border.soft` 1 px.
- 주간: 월–일 7개. 월간: 일자 단위 28–31개, x축 라벨은 1/8/15/22/말일 중심.
- VoiceOver에서는 날짜별 막대를 순서대로 탐색 가능.

### 사용처 비중

- 가로 누적 바: iPhone 74.9%, 핫스팟 25.1%.
- 아래에 2열 범례: `iPhone 54.2 GB`, `핫스팟 18.2 GB`.
- 색상 외에도 아이콘과 텍스트 레이블 사용.

참조: `assets/png/reference/Ref-Screen-Statistics@3x.png`

## C. 핫스팟

주요 사용자 작업: 핫스팟 사용량과 연결 기기를 확인.

### 레이아웃 순서

1. 제목 `핫스팟`
2. 상태 Hero 카드
3. 이번 달 핫스팟 사용량
4. 연결 기기
5. 최근 세션

### 상태 Hero 카드

- 배경: 라벤더 틴트.
- 상태 아이콘 + `핫스팟 연결됨` 또는 `연결되지 않음`.
- 연결됨일 때 기기 수를 보조 표시.
- 연결 제어 버튼은 iOS 권한/공개 API 범위에서만 제공. 제어 불가 시 읽기 전용 상태로 명확히 표현.

### 사용량

- 핵심 값 `18.2 GB`.
- 전체 사용량에서 차지하는 비율 `이번 달 데이터의 25%`.
- 7일 sparkline은 장식이 아니라 접근 가능한 차트로 구현.

### 연결 기기

- 각 행: 기기 아이콘, 이름, 연결 상태/마지막 연결, 세션 사용량.
- 행 높이 최소 60 pt.
- 알 수 없는 기기: `이름 없는 기기`로 표시하고 빈 문자열을 노출하지 않음.

참조: `assets/png/reference/Ref-Screen-Hotspot@3x.png`

## D. 설정

주요 사용자 작업: 요금제·갱신일·테마·위젯 표시 방식을 관리.

### 섹션

1. `요금제` — 월 제공량, 갱신일
2. `디자인 테마` — Classic Blue / Soft Pastel / Dark Glass
3. `위젯` — 표시 단위, 개인정보 보호
4. `데이터` — 동기화, 초기화/가져오기 관련 항목

### 테마 선택기

- 각 테마는 56 pt 이상 높이의 한 줄 선택 항목.
- 4색 미리보기 swatch + 테마명 + 체크마크.
- Soft Pastel 선택 시 체크 색 `accent.mintStrong`.
- 선택 즉시 앱 미리보기를 바꾸되 저장 실패 시 이전 선택으로 되돌리고 오류 안내.

### 위험 동작

- 데이터 초기화는 `semantic.danger` 텍스트를 사용.
- 확인 시트에서 결과와 복구 가능 여부를 명시.
- 시각적 간격으로 일반 설정과 분리.

참조: `assets/png/reference/Ref-Screen-Settings@3x.png`

## 반응형 및 콘텐츠 규칙

- 320 pt 너비에서는 Hero를 좌우 배치에서 상하 배치로 전환.
- 430 pt 이상에서는 카드 padding을 20 → 24 pt로 증가.
- iPad에서는 홈 Hero와 오늘 사용량을 2열로 배치할 수 있으나 정보 우선순위는 유지.
- `999.9 GB`, `1.25 TB`, `데이터 무제한`을 모두 테스트.
- 앱 언어가 영어일 때 `Personal Hotspot`이 잘리지 않도록 레이블은 유동 폭.
- 모든 수치는 locale-aware formatter를 사용하고, 문자열 연결 대신 localized format resource 사용.
