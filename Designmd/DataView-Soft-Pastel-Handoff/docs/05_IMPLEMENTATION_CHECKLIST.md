# 05. 구현 및 QA 체크리스트

## 토큰/구조

- [ ] 색상과 간격이 화면별 하드코딩이 아니라 공용 테마 토큰에서 제공된다.
- [ ] Classic Blue, Soft Pastel, Dark Glass 전환이 데이터/내비게이션 상태를 초기화하지 않는다.
- [ ] 앱과 위젯이 동일한 사용률 구간 및 포맷터 규칙을 공유한다.
- [ ] 다크 모드가 단순 색 반전이 아니라 지정된 surface/text 토큰을 사용한다.

## 홈

- [ ] 393 pt 너비에서 핵심 값과 게이지가 겹치지 않는다.
- [ ] 320 pt 너비 또는 AX Dynamic Type에서 Hero가 세로 레이아웃으로 전환된다.
- [ ] `54.2 + 18.2 = 72.4 GB`, `160 - 72.4 = 87.6 GB`가 일치한다.
- [ ] 오류 시 캐시 값과 마지막 갱신 시각을 함께 표시한다.

## 통계

- [ ] 주/월 전환 시 차트 높이와 주변 레이아웃이 점프하지 않는다.
- [ ] 차트가 색상 외의 레이블로도 데이터 계열을 구분한다.
- [ ] VoiceOver로 날짜별 막대와 값에 접근할 수 있다.
- [ ] 빈 기간과 0 사용량이 오류처럼 보이지 않는다.

## 핫스팟

- [ ] 연결/미연결/권한 없음/데이터 없음 상태가 각각 구분된다.
- [ ] 기기명 없음과 매우 긴 기기명에서도 행이 깨지지 않는다.
- [ ] OS가 허용하지 않는 핫스팟 제어를 암시하는 버튼이 없다.

## 설정

- [ ] 선택 테마를 체크 아이콘과 텍스트로 확인할 수 있다.
- [ ] 테마 변경이 앱과 위젯에 반영된다.
- [ ] 초기화 등 위험 동작은 확인 절차와 결과 설명이 있다.

## 위젯

- [ ] Small/Medium/accessory family를 실제 Widget preview에서 확인했다.
- [ ] 콘텐츠 여백은 WidgetKit 환경값을 존중한다.
- [ ] 오래된 데이터와 privacy redaction 상태가 구현됐다.
- [ ] tinted/monochrome rendering에서 텍스트와 게이지가 사라지지 않는다.
- [ ] 딥링크가 올바른 앱 화면으로 이동한다.

## 접근성

- [ ] 일반 본문 대비 4.5:1, 큰 텍스트/도형 대비 3:1을 충족한다.
- [ ] 터치 대상이 최소 44 × 44 pt다.
- [ ] VoiceOver 순서가 시각적 읽기 순서와 같다.
- [ ] Reduce Motion에서 게이지/숫자 애니메이션이 축소된다.
- [ ] Increase Contrast에서 경계와 상태가 명확하다.
- [ ] AX5에서 잘림 없이 세로 스크롤 가능하다.

## 데이터 경계값

- [ ] 0 B, 500 MB, 9.99 GB, 99.9 GB, 999.9 GB, 1.25 TB
- [ ] 0%, 45%, 79%, 80%, 94%, 95%, 100%, 110%
- [ ] 제공량 0/미설정/무제한
- [ ] 음수 또는 NaN 입력은 사용자에게 노출되기 전에 안전하게 정규화
- [ ] 한국어, 영어, 24시간제/12시간제, 다양한 숫자 구분자

## 시각 회귀

- [ ] 기준 PNG와 핵심 프레임의 차이가 의도된 변경인지 확인했다.
- [ ] Light/Dark 각 1개 이상 실제 기기 또는 Simulator 스크린샷을 보관했다.
- [ ] 배경 이미지가 늘어나거나 찌그러지지 않는다.
- [ ] 앱 아이콘이 60 pt 및 Spotlight 크기에서도 형태를 유지한다.
