# 남은기가

남은기가는 iPhone의 셀룰러 데이터 사용량을 앱 설치 이후부터 로컬에서 집계하고, 홈 화면 및 잠금 화면 위젯에서 요약해 보여주는 iOS 17+ 앱입니다.

첫 출시 버전에서는 핫스팟 전용 화면·설정·측정·알림을 제거했습니다. 해당 기능의 원본은 Git 태그 `baseline/dataview-with-hotspot-2026-09-28`에 보존되어 있습니다. 이전 버전의 저장 자료를 읽을 때도 셀룰러 사용 기록과 요금제 설정을 유지합니다.

## 시작하기

Xcode 27 이상과 XcodeGen이 필요합니다.

```bash
xcodegen generate
open 남은기가.xcodeproj
```

실기기에서 앱 그룹을 사용하려면 `project.yml`과 두 entitlement 파일의 번들 식별자/App Group을 본인의 Apple Developer Team에 맞게 변경하세요. App Group을 지원하지 않는 Personal Team 빌드는 `Config/DataViewPersonal.entitlements`를 `CODE_SIGN_ENTITLEMENTS`로 지정하면 공유 Keychain을 통해 위젯 요약값을 전달합니다.

2026-09-28 기준 `1.0.0 (9282)`를 iPhone 16 Pro에 개발 서명으로 업데이트 설치하고 실행했다. 기존 요금제·테마·셀룰러 기록을 유지했으며, 단위·회귀 테스트 101개와 주요 화면 UI 테스트 1개가 통과했다. Release 무서명 빌드도 통과했으며, App Store/TestFlight 배포 준비 상태는 [출시 체크리스트](RELEASE_CHECKLIST.md)를 따른다.

## 입력값 다시 설정

설정 → 입력값 초기화 → 다시 설정에서 요금제·사용량 보정값·알림을 새로 입력합니다. 저장 전 취소하면 기존 설정이 유지됩니다. 현재 통신사 사용량을 입력하거나, 저장 시점부터 0으로 시작하려면 사용량에 `0`을 입력하세요. 새 기준을 잡기 위해 셀룰러 인터페이스를 읽을 수 있어야 하며, 실패하면 기존 설정을 유지합니다.

일별 측정 기록과 테마는 삭제하지 않습니다. 따라서 통계의 과거 기록 합계와 재설정한 월 사용량은 다를 수 있습니다.

## 개인정보와 측정 범위

- 사용량과 설정은 기기에만 저장합니다.
- 공개 네트워크 인터페이스 카운터의 변화량을 집계하므로 통신사 청구량과 다를 수 있습니다.
- 설치 전 사용량은 알 수 없습니다.
- 표시값은 기기에서 관찰한 셀룰러 변화량에 사용자가 입력한 통신사 기준값을 합친 값입니다.
- 통신사 표시값과 차이가 생기면 앱의 `통신사 값 맞추기`에서 다시 동기화합니다.
- 셀룰러 인터페이스에서 관찰한 전체 데이터만 집계하며, 연결 기기별 사용량이나 별도 공유 데이터 한도는 제공하지 않습니다.
